Tenant-domain mapping and fallback
- How hostnames map to tenants
  - Middleware resolves X-Forwarded-Host/Host → SELECT tenant_id FROM tenant_domains WHERE host=$1; else fallback to DEFAULT_TENANT_ID
- Admin endpoints to manage mappings
  - GET /admin/tenants/:id/domains; POST /admin/tenants/:id/domains; DELETE /admin/domains/:host
- Schema for mapping
  - tenant_domains(host PRIMARY KEY, tenant_id uuid, verified_at)
